# 작업: T04 픽셀 아트와 화면

## 상태: 완료

## 목표
레트로 픽셀 아트 웹 게임을 완성합니다. 키보드 조작 안내, 시작과 재시작, 점수 및 최고 점수, 플레이와 넘어짐 상태를 보기 좋게 구현합니다.

## 결정 요약
- 제공된 참고 이미지에서 영감을 얻은 독창적인 Canvas 도형 픽셀 아트를 사용합니다. 저작권이 있는 게임 그림은 사용하지 않고 외부 에셋 의존성도 추가하지 않습니다.
- 조작 안내와 Enter/Space 시작 키를 보여주는 대기 화면을 제공합니다. 균형을 잃은 뒤에는 최종 점수와 Enter/Space 재시작 안내를 표시합니다.

## 구현 내용

### I01. 임시 장면을 픽셀 아트 배경과 플레이어로 교체
- 관련 파일:
  - `src/game.js` :: 장면, 플레이어, 다리, 장애물, 오버레이 렌더링; 수정
  - `style.css` :: 픽셀 게임 프레임, 조작 안내와 포커스 스타일; 수정
- 세부 사항:
  - Canvas 크기 960x540에 정수 좌표를 사용해 장면을 그립니다. `imageSmoothingEnabled=false`를 유지합니다. 보라색에서 어두운색으로 이어지는 4~6개 하늘 띠, 먼 언덕 윤곽, 오른쪽 큰 나무 수관, 풀밭 경계, 아래쪽 어두운 흙/발판을 표현합니다. 게임 지면 기준 y=390을 유지합니다.
  - 어두운 재킷, 밝은 셔츠, 바지, 머리카락과 분리된 양다리/발로 사람 실루엣을 그립니다. 다리 높이와 숙이기 상태를 자세에 반영합니다. 균형 상실 시 기존 넘어짐 시간과 균형 부호를 사용해 몸 중심을 축으로 회전합니다.
  - 장애물은 식별하기 쉬운 독창적인 픽셀 도형으로 그립니다. 충돌 상자와 위치는 기존 값을 유지합니다.
  - 그리기 순서는 하늘, 먼 언덕, 나무, 지면, 장애물, 플레이어, 점수판, 오버레이입니다.

### I02. 준비, 플레이, 넘어짐, 게임 오버 화면 및 최고 점수
- 관련 파일:
  - `src/game.js` :: 상태 전환, 오버레이, 입력 연동, 저장소; 수정
  - `index.html` :: 간결하고 접근성 있는 키 안내; 수정
  - `style.css` :: 키보드 안내 배치; 수정
- 함수 서명:
  ```js
  Game.startRun(): void
  Game.finishRun(): void
  Game.drawOverlay(title: string, lines: string[]): void
  ```
- 상태별 동작:
  - 초기 상태 `'ready'`: 제목 `두 발 클롭`, 한 줄 목표 설명, 모든 조작 키, `엔터 또는 스페이스를 눌러 시작`을 표시합니다. 시뮬레이션과 점수는 초기값 그대로 둡니다. Enter 또는 Space를 누르면 `startRun()`을 호출합니다.
  - 플레이 시작 시 점수/거리, 플레이어 상태, 장애물 목록, 생성 타이머, 균형, 경과 시간을 초기화합니다. 최고 점수는 유지합니다.
  - `'falling'`: 균형 상실로 시작된 기존 0.65초 애니메이션을 재생합니다. 넘어지는 동안 점수, 거리, 장애물 생성과 이동을 멈춘 뒤 gameover로 전환합니다.
  - `'gameover'`: `넘어졌습니다`, 최종 점수, 최고 점수, 회피한 장애물 수, `엔터 또는 스페이스를 눌러 다시 시작`을 표시합니다. Enter/Space 입력 하나로 `startRun()`을 호출합니다.
  - 최고 점수는 localStorage 키 `twoLeggedClopBestScore`에 저장합니다. 유한한 0 이상의 숫자만 읽고, 게임 종료 후 갱신합니다. 브라우저 저장소 접근 예외를 처리해 저장이 제한된 환경에서도 게임이 동작하게 합니다.
  - 플레이 중 점수판에 현재 점수, 최고 점수, 난이도 레벨, 회피 횟수, 균형 게이지를 표시합니다. 시스템 고정폭 글꼴과 충분한 명암 대비를 사용합니다.
- 접근성 있는 HTML 안내에 다음 조작을 명시합니다: 방향키(← 오른발 들기, → 오른발 내리기, ↑ 왼발 내리기, ↓ 왼발 들기), A/D 이동, W 점프, S 숙이기, Enter/Space 시작 또는 재시작. 작은 화면에서도 안내를 볼 수 있게 합니다.

## 완료 조건
- [ ] 준비, 플레이, 넘어짐, 게임 오버 상태가 명확하게 구분되고 올바르게 전환됩니다.
- [ ] 픽셀 아트 장면과 플레이어가 크기 조절 후에도 선명하고 게임 요소를 알아볼 수 있습니다.
- [ ] 키 안내가 실제 조작과 일치하고 좁은 화면에서도 보입니다.
- [ ] 저장소를 사용할 수 있으면 새로고침 후 최고 점수가 유지되고, 사용할 수 없어도 게임이 멈추지 않습니다.
- [ ] Enter와 Space로 중복 이벤트나 애니메이션 루프를 만들지 않고 시작 및 재시작할 수 있습니다.
