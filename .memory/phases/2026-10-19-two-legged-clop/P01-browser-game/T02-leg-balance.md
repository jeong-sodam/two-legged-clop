# 작업: T02 다리와 균형

## 상태: done

## 목표
양쪽 다리를 독립적으로 조작하고, WASD로 몸을 회피 동작시키며, 알아보기 쉬운 균형 게이지와 회복 가능한 불균형 및 넘어짐 처리를 구현합니다.

## 결정 요약
- 방향키 배치: ← 오른발 들기, → 오른발 내리기, ↑ 왼발 내리기, ↓ 왼발 들기. WASD 배치: A/D 좌우 이동, W 점프, S 숙이기.
- 발 높이 차이와 입력 타이밍에 따라 균형이 변합니다. 반대쪽 다리 입력으로 회복할 수 있습니다. 균형을 잃으면 게임이 끝나며, 장애물 충돌은 실패 조건이 아닙니다.

## 구현 내용

### I01. 키보드 상태 추적 및 브라우저 단축키 차단
- 관련 파일:
  - `src/input.js` :: `Input` 클래스; 신규
  - `src/main.js` :: `Input`을 만들고 `Game`에 전달; 수정
- 함수 서명과 타입:
  ```js
  export class Input {
    constructor(target: Window)
    isDown(code: string): boolean
    consumePressed(code: string): boolean
    destroy(): void
  }
  ```
- 데이터 필드:
  - `down: Set<string>`: 현재 누르는 `KeyboardEvent.code` 값.
  - `pressed: Set<string>`: 한 번 누른 후 아직 소비되지 않은 코드.
  - 지원 키: `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `KeyA`, `KeyD`, `KeyW`, `KeyS`, `Enter`, `Space`.
- 지원 키의 keydown 이벤트에서 기본 동작을 막습니다. 이미 눌린 키가 아닐 때만 `pressed`에 추가하고 `down`에도 추가합니다. keyup에서 `down`에서 제거합니다. 창 포커스를 잃으면 두 집합을 비웁니다. `consumePressed`는 해당 코드가 있는 경우 true를 반환하고 집합에서 제거해 한 번만 소비되게 합니다.

### I02. 다리, 몸, 균형 시뮬레이션
- 관련 파일:
  - `src/game.js` :: 게임 모델과 입력에 따른 갱신; 수정
- 데이터 구조:
  ```js
  player = {
    x: 220, y: 390, vx: 0, vy: 0,
    leftFoot: 0.5, rightFoot: 0.5,
    leftFootVelocity: 0, rightFootVelocity: 0,
    balance: 0, // 정규화 값 -1..1
    grounded: true, crouching: false
  }
  ```
  - 균형값 양수는 오른쪽으로 기울어짐, 음수는 왼쪽으로 기울어짐을 뜻합니다. 절댓값이 1 이상이면 넘어지기 시작합니다.
  - 발 높이 범위는 0(완전히 내림)부터 1(완전히 올림)까지입니다.
- playing 상태에서 프레임별 처리:
  1. 방향키를 누르고 있는 동안 해당 발 높이를 초당 2.8씩 바꿉니다. 반대 방향 키는 발을 내립니다. 발 높이는 `[0, 1]`로 제한합니다. 오른발은 ←로 들고 →로 내리며, 왼발은 ↓로 들고 ↑로 내립니다.
  2. `heightDifference = rightFoot - leftFoot`로 둡니다. `balance += (heightDifference * 0.9 - balance * 0.35) * deltaSeconds`를 적용합니다. 이번 프레임에 오른발을 들면 초당 `+0.22`, 왼발을 들면 초당 `-0.22`를 더하고 deltaSeconds를 곱합니다. 균형은 `[-1.2, 1.2]`로 제한합니다.
  3. A/D 입력 시 수평 목표 속도를 각각 -150/+150 픽셀/초로 설정합니다. 둘 다 누르지 않으면 마찰로 초당 500 픽셀/초²만큼 속도를 0에 가깝게 줄입니다. 플레이어 x는 `[90, 420]` 범위로 제한합니다.
  4. grounded 상태에서 W를 눌렀을 때 `vy = -430`으로 설정하고 grounded를 false로 바꿉니다. 중력은 1100 픽셀/초²입니다. 지면 기준 y=390에 닿으면 `vy=0`, grounded=true로 설정합니다.
  5. S를 누르고 있는 동안 `crouching=true`로 둡니다. 숙이기는 그려지는 자세만 바꾸고 다리 값은 바꾸지 않습니다.
  6. `abs(balance) >= 1`이면 상태를 `'falling'`으로 바꿉니다. 0.65초 동안 회전하고 사라지는 넘어짐 애니메이션을 재생한 뒤 `'gameover'`로 전환합니다. 이 작업 단계에서 실패 조건은 균형 상실뿐입니다.
- `Game` 생성자가 `Input` 인스턴스를 받도록 하고 `main.js`도 함께 수정합니다. 이 작업에서는 장애물을 구현하지 않습니다.

### I03. 다리와 균형 상태 그리기
- 관련 파일:
  - `src/game.js` :: 플레이어 및 균형 게이지 렌더링; 수정
- 몸통과 위·아래 다리를 간단한 사람 모양으로 그리고 양쪽 발을 구분해 발 높이를 나타냅니다. 좌측 상단 고정 영역에 중앙 표시가 있는 균형 막대를 둡니다. 기울기 절댓값이 0.65 미만이면 녹색, 0.65~0.84이면 노란색, 0.85 이상이면 빨간색을 사용합니다. T04 전까지는 임시 그림 스타일을 유지합니다.
