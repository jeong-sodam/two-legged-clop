# 네발 클롭

무작위로 바뀌는 네 개 또는 여덟 개의 키를 외워 팔다리를 따로 움직이는 오리지널 픽셀 아트 브라우저 게임입니다. 머리가 장애물에 부딪치지 않도록 기어가세요.

## 바로 플레이

[네발 클롭 플레이하기](https://jeong-sodam.github.io/two-legged-clop/)

## 조작법

- 모드 선택 화면에서 `←` / `→`로 노말 또는 하드를 선택합니다.
- `Enter` 또는 `Space`로 시작하면 매 판 새 키 배정이 10초간 표시됩니다.
- 노말은 무작위 네 키를 누르고 있는 동안 해당 팔다리를 듭니다. 키를 놓으면 내립니다.
- 하드는 무작위 여덟 키를 사용합니다. 팔다리마다 들기와 내리기 키가 따로 배정됩니다.
- 화면 아래 상태 표시로 각 팔다리가 현재 들려 있는지 확인할 수 있습니다.
- 다섯 테마의 맵과 장애물이 무작위로 등장합니다. 머리가 장애물에 닿으면 넘어집니다. 몸이나 팔다리만 닿으면 장애물 효과에 따라 미끄러지거나 밀릴 수 있습니다.
- 개인 최고 거리는 이 브라우저에 저장됩니다. 온라인 랭킹과 로그인은 제공하지 않습니다.

## 로컬에서 실행

저장소 루트에서 정적 파일 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 <http://localhost:8000/>을 엽니다. GitHub Pages 배포본은 위 링크에서 플레이할 수 있습니다. 게임은 JavaScript 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 로컬 서버를 사용하세요.
