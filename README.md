# 두 발 클롭

다리마다 따로 조작해 균형을 잡고 장애물을 피하는 레트로 픽셀 아트 브라우저 게임입니다.

## 바로 플레이

[두 발 클롭 플레이하기](https://jeong-sodam.github.io/two-legged-clop/)

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 오른발 들기 / 내리기 |
| ↑ / ↓ | 왼발 내리기 / 들기 |
| A / D | 좌우 이동 |
| W | 점프 |
| S | 숙이기 |
| Enter / Space | 시작 또는 다시 시작 |

## 로컬에서 실행

저장소 루트에서 정적 파일 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 <http://localhost:8000/>을 엽니다. 게임은 JavaScript 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 로컬 서버를 사용하세요.
